## 07 기억 장치의 개요
컴퓨터의 기억장치
	- 기억장치는 주기억장치와 보조기억장치로 구분
	- 주기억 장치: cpu와 접근 통신이 가능한 기억장치
	- 보조기억장치: 현재는 필요하지 않은 프로그램이나 데이터르 저장하고 있다가 필요 할 대 주기억장치로 전송하는 장치

 - 기억장치의 성능 평가 요소
	 - 기억장치의 성능 평가 요소
		- 기억용량
			- 기억장치에 저장 할 수 있는 데이터의 총량
			- 단위는 비트, 바이트, 워드 
			- 접근 시간(Access Time)
			 기억 장치에 저장된 데이터를 읽거나 새로운 데이터를 기록하는 데 걸리는 시간
			사이클 시간(Cycle Time)
				- 기억 장치에 두 번 연속 접근하는 데 걸리는 최소 시간
				- 비파괴 기억 장치는 사이클 시간과 접근 시간이 동일
				- 자기 코어 기억 장치와 같은 파괴 기억 장치는 정보를 읽으면 기억장치에 저장된 정보가 삭제되므로 읽기 위한 접근 시간과 정보를 다시 저장하기 위한 복원 시간을 합한시간이 사이클 시간

 - 기억 장치의 분류
	-	제조 재료에 따른 기억 장치의 유형
		-	반도체 기억 장치 : 반도체 물질인 실리콘 칩을 
		-	자기 표면 기어 장치 : 자화(자석 같은 특성) 물질로 코팅된 표면에 정보 저장
	- 데이터를 저장하는 성질에 따른 기억 장치의 유형
		- 휘발성 기억 장치 (RAM), 비휘발성 기억 장치(ROM)
	- 접근 방법에 따른 기억 장치의 유형
		- 순차적 접근 : 데이터가 저장되는 순서에 따라 기억장치에 순차적 접근
		필요한 데이터가 저장된 위치에 따라 접근 시간이 결정
		- 직접 접근 : 기억 장소 근처로 이동한 다음 순차적으로 검색, 최정적으로 원하는 데이터에 접근 위치와 접근 위치에 따라 접근시간이 결정

## 주기억 장치의 분할 
시스템 프로그램 영역 
- 운영체제가 저장되는 곳으로 상주 구역과 비상주 구역으로 구분 -

사용자 응용 프로그램 영역 
- 일반 프로그램이 기억되는 곳으로 시스템 프로그램의 제어에 의해 동작
- 여러 부분으로 분할하고 독립된 프로그램을 기억시켜 **다중 프로그래밍 방식으로 동작**하게 할수있음
- 운영체제가 사용자 응용 프로그램 각각의 독립된 영역을 보호하는 기억 보호를 수행

단일 사용자 할당 기법
- 운영체제가 차지하는 부분을 제외한 나머지 기억 공간을 한 사용자 응용 프로그램이 사용하게 하는 방식
	- 장점
		- 사용자에게 최대한 융통성을 제공
		- 최대의 단순성, 최소의 비용을 만족
		- 특별한 하드웨어 필요 X, 운영체제 SW또한 필요 X
	- 단점 
		- 사용자가 사용하는 부분 이외는 낭비 
		- 입력과 출력을 수행하는 동안 주기억 장치 내의 프로그램이 CPU를 계속 쓸 수 없어 **유휴상태**가 되므로 **활용도가 매우 낮음**
		- **프로그램이 주기억 장치의 용량보다 크면 실행하기 어렵다**

오버레이 기법
- 주기억장치보다 큰 프로그램을 실행하기 위한 기법
- 보조기억장치에 저장된 프로그램을 여러개의 조각으로 분할 이후 필ㅇ한 조각을 차례대로 주기억장치에 할당하는 방법


고정 분할 할당 기법
- 각 응용 프로그램에 동일한 크기의 분할된 구역을 고정 할당하는 방식
	- 장점
		- 프로그램을 적재하고 남은 공간에 다른 프로그램을 적재 하여 실행 > 프로세서와 기억 장치 같은 자원의 활용도가 크게 향상
		- 동시에 여러 프로그램을 주기억 장치에 적재하여 실행하는 다중 프로그래밍 기법이 가능
	- 단점
		- 할당되는 저장 공간이 작고 저장될  프로그램이 큰 경우 프로그램이 작은 단위로 쪼개지는 단편화 문제가 발생
		- 프로그램이 할당된 분할 구역의 크기가 일치하지 않으면 남는 공간이 생김

- 실행할 프로그램의 크기를 알고 있어야 함
- 다중 프로그래밍을 위해 사용되었지만 현재는 사용되지 않음


가변 분할 할당 기법
- 단편화를 해결하기 위해 각 작업에 필요한 만큼의 공간만을 할당하는 방식
- 고정 분할 할당 기법에 비해 실행될 프로세스 킈에 대한 제약이 적음
-  '' 기법의 단편화 문제를 해결할 수 있지만 영역과 영역 사이에 단편화가 발생될 수 있음

기억 장치의 집약
- 주기억 장치를 검사하여 공백인 빈 영역을 하나의 커다란 빈 영역으로 만드는 것

- 장점
	- 기억 장소에 분산된 공간을 한 곳에 모아 사용 가능한 큰 영역을 만듦으로써 낭비를 줄임

- 단점 
	- 기억 장소를 집약하는 동안 전체 시스템은 수행 중이던 일단 중지해야 하며, 집약하는데 많은 시간이 소모
	- 수행 중이던 프로그램과 데이터를 주기억 장치 내의 다른 장소로 이동하기 때문에 각각의 위치 및 이와 관련된 내용을 수정해야 함
