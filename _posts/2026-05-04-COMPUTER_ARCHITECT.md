# 컴퓨터 아키텍쳐 0504 수업 메모

## ch06 : cpu와 마이크로프로세서

### 마이크로프로세서
Microprocessor 
- 컴퓨터에서 명령을 수행하고 데이터를 처리하는 CPU를 칩 형태로 만든 직접회로
- 폰 노이만(Von Neumann) 컴퓨터 구조

머신 사이클(Machine Cycle)
	프로그램을 구성하는 명령어는 4단계를 거침, 이러한 단계별 명령어 수해오가정이 CPU에서 이루어지는 것을 말함
 
 > 인출, 해독, 실행, 저장

### 클럭 속도와 명령어 처리 속도
- CPU를 비롯한 컴퓨터의 모든 부품은 특정 신호에 맞춰 동작하는데, 이러한 신호를 (Clock)이라고 함.
- 클록 주파수는 1초에 클록이 몇 번 발생하는지를 의미
- 1초에 1번 클록이 발생하는 것을 1Hz라고 한다.
- 1초에 클록이 **10<sup>6</sup>번** 발생하면 클록 주파수의 단위는 **MHz**, 1초에 클록이 **10<sup>9</sup>번** 발생하면 클록 주파수의 단위는 **GHz**

### 레지스터
- 임의의 데이터에 대한 처리 결과를 일시적으로 저장하거나 내용을 이동할 때 잠시 보관하는 장소
- 고속으로 동작할 수 있게 플립플롭 설계
- **레지스터 간 전송**
	- 레지스터가 다른 레지스터에 데이터를 쓰거나 저장된 데이터를 읽는 동작은 직렬 전송과 병렬 전송으로 구분
	- 직렬 전송 방식 : 이웃한 플립플롭 회로로 1비트씩 이동하고 맨 끝의 플립플롭이 또다른 레지스터의 플립플롭으로 전송하는 방식
	- 병렬 전송 방식 : 레지스터에 기억된 전체 내용을 하나의 제어 신호로 다른 레지스터에 동시에 전송하는 방식
	- 버스 전송 방식
		- 디코더를 이용한 단일 버스 연결: 레지스터 4개에서 단일 버스를 통해 데이터를 공동으로 전송하려는 경우 > 레지스터를 선택하기 위해 2비트가 입력되는 디코더를 사용
		- 멀티플렉서와 디멀티플렉서의 단일 버스 연결: 여러 개의 레지스터 중 선택된 하나의 레지스터에 단일 버스를 통해 수신되는 방식으로, 디멀티플렉서 회로를 사용.
	- 기억 장치 전송 방식
		- 주기억 장치에서 데이터 쓰기/읽기 동작을 수행하려면 해당 위치를 알려주는 주소 번지가 필요.
		- 주소 번지를 저장하는 기억 장치 주소 레지스터, 주기억 장치에서 읽거나 기록할 때 임시로 저장하는 기억 장치 버퍼 레지스터가 필요하다.
		- 데이터의 주소 번지가 여러 레지스터에 저장된 경우, 멀티플렉서를 사용하며 필요한 데이터가 기억된 레지스터를 선택할 수 있음.
> 디멀티플렉서는 데이터 자체를 선택된 출력으로 보내는 장치
> 디코더는 모든 레지스터에 연결된 데이터 중에서, 어떤 레지스터만 쓰기를 허용하는 장치
> 디코더 방식이 더 일반적&효율적이기에 CPU내부 회로 설계에 많이 사용

### ALU
우선 연산될 데이터와 연산 결과를 저장하는 레지스터가 있어야함.
연산의 상태를 나타내기 위한 상태 레지스터의 연결도 필요
가산기, 누산기, 기억 장치 버퍼 레지스터 등이 필요.
	- 논리 연산 회로
		- 논리 게이트를 이용하여 조합 논리회로를 구성하면 다양한 논리 연산을 수행 가능
		- data A, B를 입력하는 회선과 연산의 종류를 선택하는 회선이 존재
		- 입력되는 데이터 A, B를 가지고 연산 지시에 따라 And, Or, Xor, Not 연산을 수행
		- 연산 지시 신호는 논리 연산 뿐만 아니라 결과가 기억될 장소를 0으로 지우는 **지움선**, Not 연산으로 1의 보수가 되게 하는 **보수 회선**에 의해 선택될 수 있음.

- 산술 논리 연산 장치
	- 설계된 산술 연산 회로와 논리 연산 회로를 조합하면 다음과 같은 산술논리 연산장치가 완성됨
	
- 이동 회로
	- 이동 레지스터라고도 불리는 이동기에서의 이동 방향은 좌측과 우측
	- 이동할 때 이동 방향의 마지막 비트 값은 바깥으로 밀려남
	- 반대편의 첫 비트는 상대적으로 공백이 생기는데 여기에 0 or 1이 채워짐

### CPU의 기능과 동작

CPU가 모든 명령어에 대해 공통적으로 수행하는 기능은 명령어 인출과 해독입니다.
* **명령어 인출 기능**: 주기억 장치에 저장되어 있는 명령어를 읽어오는 것
* **명령어 해독 기능**: 읽은 명령어로 수행할 동작을 결정하기 위해 인출된 명령어를 해독하는 것

| 기능 | 설명 |
|---|---|
| 데이터 인출 | 명령어를 실행 시 데이터가 필요한 경우 기억장치나 입출력 장치에서 그 데이터를 읽어오는 것, 연산 과정에서 사용되는 모든 데이터를 불러오는 것 |
| 데이터 처리 | 읽어온 데이터를 가지고 산술 연산이나 논리 연산을 수행 |
| 데이터 쓰기 | 데이터 처리 과정에서 수행 결과를 저장 |
