## 주기억 장치의 종류
### 자기 코어 기억장치
- 초기에 많이 사용되었던 임의 접근 컴퓨터 기억장치
- 자기 코어는 링 모양, 페라이트 라는 자성물질로 만들어져 자화가 쉬움
- 한 번 자화되면 외부 영향이 없는 한 그 상태를 유지

X,Y,Z,S가 관통하는데 
구동선은  : X, Y / 감지선 : S / 금지선 : Z 로 구분

- 자기 코어로 실제적인 기억 장치를 구성하기 위해 행렬 구조로 배치한 것을 자기 코어 행렬이라고 함
- 하나의 코어 행렬 면을 코어 플레인 (Core Plane)이라고 함
- 코어 플레인을 필요한 매수만큼 겹쳐서 한 단위의 기억 장치로 만든 것을 **코어 스택(Core Stack)**이라고 함

반도체 기억 장치
- 디지털 시스템의 프로그램이나 데이터를 저장하는 주기억 장치에 널리 사용되고 있다.
- 대부분의 반도체 기억장치는 저장 위치에 상관 없이 같은 시간에 접근이 가능한 RAM 형태
- 휘발성인 RAM과 비휘발성인 ROM으로 구분

구조
- 반도체 기억 장치 칩에는 **제어 신호 단자, 레지스터, 주소 레지스터**가 있음
ex) 
주소 길이 : 5비트 워드 : 32개 (2^5) 워드 길이 : 4bit 기억 장치 용량 : 128bit (32 * 4)
주소 길이 : 12bit 워드 : 4096개(2^12) 워드 길이 8bit 기억장치 용량 : 4069Byte

워드 : 2^(주소길이) 용량 : 워드 * 워드길이

반도체 기억장치의 동작
- 쓰기 동작
	- 기억 장치에 데이터를 저장하는 것
	1. 주소 레지스터 > 주소 버스를 통해 주소 디코더로 전달
	2. 레지스터에서 데이터 버스를 통해 기억 장치 셀 배열에 데이터 전달
	3. 데이터 쓰기
- 읽기 동작
	- 기억장치에 저장되어 있는 데이터를 인출하여 이를 요구한 장치로 전달
	1. 주소 레지스터 > 주소 버스 를 주소 디코더로 전달 (이진수 주소)
	2. 주소에서 데이터 읽기
	3. 데이터 레지스터로 데이터 버스를 통해 전달

임의 접근 기억 장치
- 보통 **RAM**이라고 일컫음
- RAM은 크기가 **작고, 신뢰성이 높으며, 성능이 우수하고, 소비 전력이 적다**
- RAM은 대부분의 컴퓨터에서 주 기억 장치로 사용되는 중

특징과 용도
- 보조 기억 장치에서 데이터 또는 명령을 읽어 처리하려 할 때 CPU와 보조 기억 장치의 속도 차이를 극복하기 위해 보조 기억 장치보다 속도가 빠른 RAM을 중간에 놓음

RAM의 종류
- 제조상 RAM의 분류는 다음과 같음
> ram : 바이폴라 : sram / mos : sram, dram / bmos : sram

DRAM(동적 RAM)
- 충전기 커패시터에 전하를 저장하는 방식으로, 2진 데이터를 저장
- 충전기에 전하가 존재하는 지에 따라 2진수의 1과 0을 구분하여 저장
- SRAM보다 구조가 간단
- 전력 소모가 적고 가격이 낮아 대용량 기억 장치에 많이 사용된다.

쓰기 동작 :
1. R/W의 단자가 0이 되면 쓰기 동작이 설정되어 입력 버퍼는 동작 상태가 되고 출력 버퍼는 동작 불가능 상태가 됨
2. 논리 0을 저장하기 위해 Din = 0 커패시터가 충전되지 않음. 만약에 커패시터에 논리 1이 저장되어 있다면 커패시터가 방전
3. 기억 소자에 논리 1을 저장하려면 Din = 1로 하며, 저장 위치를 지정하는 행 입력이 논리 1이면 커패시터에는 양(+)의 전압이 충전됨.

RAM의 종류
 • SRAM(정적 RAM)
   플립플롭 방식의 기억 소자를 가진 RAM이다.
   전원이 공급되는 한 저장된 내용을 계속 기억하며, 복잡한 재생 클록이 필요 없다. 
   집적 밀도가 높아서 가격이 비싸며, 소용량 저장 장치에 사용된다. 
   처리 속도가 5배 정도 빨라 캐시 기억 장치에 주로 사용된다. 
   SRAM은 1비트를 저장하는 기억 소자인 플립플롭으로 구성된다. 
   RS 플립플롭과 AND 게이트가 조합된 순차 논리 회로로 구성했다.

ROM의 구성
	- 주소를 입력하여 데이터를 읽을 위치를 결정하는 주소 디코더가 있으며 기억장치의 배열과 연결되어 있음
	- ROM의 경우 플립플롭 대신 OR게이트의 연결 관계를 통해 기억 장치의 배열을 형성
	- 쓰기 동작이 없으므로 입력 단자가 없음
